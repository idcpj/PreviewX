# PreviewX — Privacy Policy (隐私政策)

*Last updated: 2026-10-05*

PreviewX ("we", "our", or "us") is dedicated to protecting your personal privacy. This Privacy Policy explains our practices regarding user data and file handling when you use the PreviewX application and its Quick Look extension.

---

## English

### 1. Zero Data Collection (No Personal Information Collected)
PreviewX is designed strictly with a **Local-First** philosophy. 
- We **do NOT** collect, transmit, store, or share any personal identifiable information (PII).
- We **do NOT** collect analytics, tracking telemetry, crash logs with personal info, or device identifiers.
- The app operates **100% locally** on your Mac.

### 2. File Access and Read-Only Operation
PreviewX is a file preview utility:
- File contents inspected via Finder Quick Look (Spacebar) or the standalone PreviewX app are read solely into local volatile memory for rendering purposes (syntax highlighting, structured tree parsing, table layout).
- We **NEVER** modify, write to, or overwrite any of your source files.
- We **NEVER** upload, transmit, or copy your files or metadata to any remote server or third party.

### 3. Network Access & Remote AI
- By default, network communication is completely disabled.
- Advanced remote AI features (if enabled by explicit user configuration in the future) are disabled by default (`allowRemoteAI = false`) and will strictly require explicit opt-in confirmation and user-provided API endpoints.

If you have any questions or feedback regarding this Privacy Policy, please open an issue on our GitHub repository or contact:

## 中文版

### 1. 零个人数据收集 (Zero Data Collection)
PreviewX 遵循严格的**本地优先 (Local-First)** 原则：
- 我们**不会**收集、传输、存储或分享任何用户的个人身份信息（PII）。
- 我们**不会**集成任何第三方数据分析 SDK、广告跟踪器或遥测工具。
- 本应用的所有核心解析与展示逻辑均 **100% 运行在您的本地 Mac 设备上**。

### 2. 文件访问与纯只读设计
PreviewX 是一款 Quick Look 增强与文件预览工具：
- 当您通过访达（Finder）空格键或 PreviewX 窗口预览文件时，文件内容仅作为即时渲染（语法高亮、大纲树、表格解析）在本地内存中做轻量解析。
- PreviewX **绝不修改**您的源文件，绝不产生写盘副作用。
- PreviewX **绝不上传**、传输或备份您的文件内容与元数据至任何远程服务器。

### 3. 网络权限与远程 AI
- PreviewX 默认无需且不发起任何网络通信。
- 未经您明确主动配置与授权，应用绝不建立外部网络连接。
