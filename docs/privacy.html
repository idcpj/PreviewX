中文版

1. 零个人数据收集 (Zero Data Collection)

PreviewX 严格遵循本地优先 (Local-First) 架构设计：

  • 我们绝不收集、传输、存储或分享任何个人身份信息 (PII)。
  • 我们绝不集成任何第三方数据分析 SDK、广告跟踪器或遥测工具。
  • 本应用的所有预览渲染逻辑 100% 运行在您的本地 Mac 内存中，绝无网络数据外发。

2. 文件只读原则与安全性

PreviewX 纯粹是一款即时预览增强工具：

  • 文件内容仅在您按下空格键或在工作台中打开时由内存读取并渲染（语法高亮、树形浏览等）。
  • 系统绝对禁止修改源文件，不产生任何就地写入副作用。
  • 系统绝不隐式执行代码，所有文件纯粹作为静态文本或数据解析，从机制上杜绝恶意脚本注入风险。

3. 网络通信规范

PreviewX 默认完全禁用外部网络请求。在未获得您主动明确授权与触发的情况下，绝不发起任何网络连接。

English

1. Zero Data Collection

PreviewX operates strictly under a Local-First philosophy:

  • We do NOT collect, transmit, store, or share any personally identifiable information (PII).
  • We do NOT include any analytics SDKs, advertising trackers, or telemetry tools.
  • All parsing and rendering is processed strictly in your local device memory.

2. Read-Only File Inspection

  • File content is read exclusively into volatile memory for real-time presentation (syntax highlighting, directory trees, table formatting).
  • We NEVER modify, alter, or write to your local files.
  • We NEVER execute file contents or run external scripts to generate previews.
